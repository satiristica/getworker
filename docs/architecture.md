# Архитектура 

## Общая модель

Getworker -> монолитное веб-приложение с модулями 

Backend сделан на Spring Boot. Фронтенд состоит из статических HTML, CSS, JS файлов и идет вместе с бэкенд в одном приложении.

OpenLDAP работает отдельно от приложения и запускается в докере. Springboot взаимодействует с LDAP по сети.
