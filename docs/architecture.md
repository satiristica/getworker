# Архитектура 

## Общая модель

Getworker -> монолитное веб-приложение с модулями 

Backend сделан на Spring Boot. Фронтенд состоит из статических HTML, CSS, JS файлов и идет вместе с бэкенд в одном приложении.

OpenLDAP работает отдельно от приложения и запускается в докере. Springboot взаимодействует с LDAP по сети.

## Ключевые компоненты

| Компонент | Ответственность |
|---|---|
| Frontend | Отображает страницы авторизации и справочника, отправляет HTTP-запросы в backend |
| Backend | Принимает HTTP-запросы, выполняет логику приложения и возвращает данные в формате JSON |
| OpenLDAP | Хранит пользователей, контактные данные и проверяет учётные данные |
| Docker Compose | Собирает backend и запускает все контейнеры проекта |
